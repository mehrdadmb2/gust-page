# VakilStay Pro — Shiraz Hospitality Landing Page

این نسخه برای GitHub Pages طراحی شده و روی همان پروژه‌ی فعلی قابل جایگزینی است.

## فایل‌های اصلی
- `index.html` — ساختار، SEO، JSON-LD، بخش‌های تعاملی و دسترسی‌پذیری
- `style.css` — تم حرفه‌ای شیراز با سه حالت `Dark / Light / Persian Garden`
- `script.js` — داده‌ها، فیلترها، برنامه‌ریز سفر، آب‌وهوا، نقشه، نظرات، محاسبه شب‌ها، اشتراک‌گذاری و فرم تماس
- `manifest.webmanifest` — قابلیت نصب به‌صورت PWA
- `sw.js` — کش اولیه برای تجربه بهتر آفلاین

## فایل‌های موجود پروژه را نگه دارید
این نسخه عمداً از فایل‌های فعلی `Logo.png`، `cover.jpeg` و `guide.pdf` استفاده می‌کند. کافی است آنها را در ریشه پروژه نگه دارید.

## نکته‌های مهم
1. موجودی و قیمت واحدها از داخل کد اختراع نشده و رزرو به لینک فعلی Jajiga همان واحد هدایت می‌شود.
2. فرم نظر روی `localStorage` همان مرورگر ذخیره می‌شود و عمومی نیست.
3. فرم تماس `mailto:` می‌سازد؛ برای ارسال واقعی سمت سرور می‌توانید بعدها Formspree، EmailJS یا بک‌اند اختصاصی وصل کنید.
4. آب‌وهوا با Open-Meteo در زمان اجرا درخواست می‌شود؛ در صورت قطع شبکه، کارت آب‌وهوا gracefully fallback می‌کند.
5. نقشه با Leaflet + OpenStreetMap است.
6. اگر `cover.jpeg`، `Logo.png` یا `guide.pdf` نام متفاوتی دارند، مسیرها را در `index.html` عوض کنید.
7. مختصات و فاصله‌های جاذبه‌ها از اطلاعات قبلی پروژه حفظ شده‌اند تا ادعای جدید و بی‌منبع درباره قیمت یا ظرفیت ایجاد نشود.

## استقرار روی GitHub Pages
محتوای این بسته را در branch اصلی پروژه قرار دهید و GitHub Pages را روی همان branch/root تنظیم کنید.
